# ۴️⃣ تعامل با محیط، آیتم‌ها و انبار

> هدف: درب، کشو، کلید، فیوز و انبار — چیزهایی که «خونه» را بازی می‌کنند.

---

## قدم ۱: یک در ساده بساز

1. Hierarchy → راست‌کلیک → **3D Object → Cube** → اسم: `DoorPanel`
   - Scale: `(1.2, 2.2, 0.08)` ← یک در به عرض ۱.۲ متر
2. یک شیء خالی بساز: **Create Empty** → اسم: `DoorPivot`
   - این Pivot جای **لولا** است! در را ببر آن‌طرف: DoorPanel را فرزند DoorPivot کن
     و Position پنل را `(0.6, 1.1, 0)` بگذار (یعنی لولا سمت چپ در).
3. روی `DoorPivot` → **Add Component → DoorController**
   - Open Angle: `−90` (جهت باز شدن — اگر برعکس بود ۹۰ بگذار)
   - Prompt: «باز کردن در»
4. برای دیوار و قاب، از Cube های ساده استفاده کن — راهنمای کامل ساخت خونه در سند ۹.

### در قفل‌دار (در سرداب)

همان مراحل بالا + تنظیمات DoorController:
- ✅ Start Locked: `true`
- Key Item Id: `key_basement`
- Locked Voice Id: (شناسه گویندگی، مثل `v_locked_room`)
- Unlock Voice Id: (شناسه گویندگی لحظه‌ی باز شدن)

بازیکن وقتی کلید key_basement را در انبار داشته باشد، تعامل = باز شدن + مصرف کلید.

## قدم ۲: کشو با آیتم پنهان (کشوی آشپزخانه)

1. یک مبل/میز ساده بساز (کوب‌های روی‌هم) — یا فعلاً یک Cube به اسم `Drawer`:
   - Scale: `(0.8, 0.25, 0.5)` — Position: داخل میز
2. روی `Drawer` → **Add Component → DrawerController**
   - Open Offset: `(0, 0, −0.45)` ← به سمت بازیکن بیرون می‌آید
   - Creak Sfx: صدای جیرجیر (بعداً می‌گذاریم)
3. آیتم پنهان: یک Cube کوچک داخل کشو (Scale: 0.15) → اسم: `HiddenFuse`
   - رویش **Add Component → PickupItem** — Item Data را بعداً می‌دهیم (قدم ۴)
   - در ابتدا تیک فعال بودنش را بردار (Inspector، بالای اسم — چک‌باکس)

وقتی کشو باز شود، HiddenFuse بعد از ۰.۴ ثانیه ظاهر می‌شود! 🐭

## قدم ۳: آشنایی با آیتم‌ها — ساخت فایل آیتم

آیتم‌ها «فایل» هستند نه کد:

1. پنجره‌ی Project → پوشه‌ی `Assets/Items` را بساز.
2. راست‌کلیک → **Create → خانه نذر → آیتم بازی** → اسم: `Fuse`
3. در Inspector فایل:
   - **Id:** `fuse` ⚠️ انگلیسی و بدون فاصله — هرگز عوضش نکن بعداً!
   - **Display Name:** `فیوز سوخته`
   - **Description:** «فیوز کهنه‌ی برق خونه. هنوز بوی سوختگی می‌ده.»
   - **Icon:** یک تصویر مربعی (می‌توانی موقتاً از Default icon یونیتی استفاده کنی)
   - **Pickup Voice Id:** `v_fuse_found`

همین کار را برای همه‌ی آیتم‌های STORY.md تکرار کن:
`key_basement` ، `photo_1` ، `photo_2` ، `photo_3`

## قدم ۴: دفترچه‌ی آیتم‌ها (برای ذخیره‌ی بازی لازم!)

1. راست‌کلیک در Project → **Create → خانه نذر → دفترچه‌ی آیتم‌ها** → اسم: `ItemDatabase`
2. در Inspector، Size لیست را `5` کن و همه‌ی فایل‌های آیتم را بکش داخلش.

## قدم ۵: برداشتن آیتم

روی هر شیء قابل برداشتن (کلید روی میز و...):
1. **Add Component → PickupItem**
2. Item: فایل آیتم مربوطه را بکش داخلش.
3. حتماً یک **Collider** داشته باشد (Cube/Mesh خودش دارد).

بازیکن نگاه کند → متن «برداشتن» → تعامل → آیتم می‌رود داخل انبار + گویندگی پخش می‌شود.

## قدم ۶: انبار (Inventory)

1. Hierarchy → **Create Empty** → اسم: `Inventory`
   - **Add Component → InventoryManager** ← Item Database را بده.
2. در Canvas:
   - **UI → Image** → اسم: `InventoryPanel` — تمام‌عرض پایین، نیمه‌شفاف تیره
     - ✅ در شروع غیرفعالش کن (تیک بالای Inspector را بردار)
   - فرزندش: **UI → Panel** یا Image به اسم `Content`
     - **Add Component → Grid Layout Group** — Cell Size: `(140,140)`، Spacing: `(16,16)`
   - فرزند InventoryPanel: **UI → Text** به اسم `DescriptionText` — فونت Vazirmatn
3. یک دکمه‌ی قالب: روی `Content` راست‌کلیک → **UI → Button** → اسم: `SlotTemplate`
   - Width/Height: `140` — ✅ غیرفعالش کن (تیک را بردار) — این «قالب» است و در بازی کپی می‌شود.
4. روی `InventoryPanel` → **Add Component → InventoryUI**
   - Panel: خودش / Content: `Content` / Description Text: `DescriptionText`
   - Slot Prefab: `SlotTemplate` را بکش داخلش
5. دکمه‌ی انبار HUD (سند ۳) → On Click → `InventoryPanel → InventoryUI → TogglePanel`

تست: ▶ را بزن، یک PickupItem بساز، بردارش، دکمه‌ی انبار را بزن — باید آیکونش باشد.

## قدم ۷: جای‌گذاری آیتم — فیوز در جعبه‌ی برق ⚡

این همان `ItemSocketPuzzle` است — کاربرد اولش جعبه‌ی برق:

1. یک Cube روی دیوار راهرو: Scale: `(0.5, 0.7, 0.15)` → اسم: `FuseBox`
2. یک Cube کوچک‌تر داخلش (فرزند FuseBox): `FuseVisual` — Scale: `(0.3, 0.4, 0.05)`
   - ✅ غیرفعال در شروع
3. روی `FuseBox` → **Add Component → ItemSocketPuzzle**
   - Required Item Id: `fuse`
   - Filled Visual: `FuseVisual`
   - Filled Hint: «تیز... برق برگشت!»
4. در بخش **On Filled** (UnityEvent): `+` → بکش چراغ‌های خونه که روشن شوند
   (در سند ۶ کاملش می‌کنیم)
