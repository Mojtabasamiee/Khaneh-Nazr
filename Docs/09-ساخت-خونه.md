# ۹️⃣ ساختن خونه‌ی ایرانی و نورپردازی 🏚️

> هدف: ساخت خونه‌ی قدیمی ایرانی با ابزارهای خود یونیتی (بدون مدل آماده) +
> نور ترسناک بهینه برای موبایل.

---

## بخش الف: نقشه‌ی خونه (طرح کلی)

```
                    ┌─────────┐
                    │ اتاق    │
                    │مادربزرگ │← قفل کد، شعر حافظ، قاب عکس‌ها
            ┌───────┼─────────┤
  در اصلی → │       │ راهرو   │← ۳ آینه پوشیده، جعبه‌ی برق
            │ نشیمن ├─────────┤
            │       │ آشپزخانه│← کشوی فیوز، کابینت‌ها
            └───┬───┴────┬────┘
                │  راه پله │
                └────┬────┘
                ┌────┴────┐
                │  سرداب  │← سه شمع، جعبه‌ی نذر، تاریکی!
                └─────────┘
```

## بخش ب: ابزار ساخت سریع — ProBuilder؟ نه، راه ساده‌تر!

برای خونه‌ی ترسناک، ساده‌ترین روش: **کوب‌ها (Cube) + متریال**.
(ProBuilder هم خوب است ولی برای مبتدی، کوب ساده‌تر و سبک‌تر است.)

### ساخت یک اتاق در ۶۰ ثانیه:

1. **زمین:** Cube → Scale: `(8, 0.2, 8)` — Position Y: `−0.1`
2. **دیوار پشت:** Cube → Scale: `(8, 3, 0.2)` — Position: `(0, 1.5, 4)`
3. دیوارهای دیگر را کپی کن (Ctrl+D) و جابه‌جا کن.
4. برای در/پنجره: دو کوب کنار هم به جای یک دیوار یکپارچه بگذار (فاصله = قاب در).

💡 نکته: برای هر اتاق یک **Create Empty** به اسم اتاق بساز و همه‌ی دیوارهایش
را فرزندش کن — صحنه مرتب می‌ماند.

### چیدمان اتاق‌ها (مختصات پیشنهادی):

| اتاق | Position مرکز | ابعاد تقریبی |
|---|---|---|
| نشیمن | `(0, 0, 0)` | 8×8 |
| آشپزخانه | `(9, 0, 0)` | 6×6 |
| راهرو | `(0, 0, 8)` | 3×10 |
| اتاق مادربزرگ | `(0, 0, 15)` | 6×6 |
| راه پله + سرداب | `(-8, -3, 8)` | 4×8 (سرداب پایین‌تر: Y = −3) |

برای راه پله: ۱۰-۱۲ کوب پله‌ای با ارتفاع افزایشی (هر پله: 0.2 متر بالا، 0.3 متر جلو).

## بخش ج: متریال‌های خونه‌ی ایرانی 🎨

پوشه‌ی `Assets/Materials` — راست‌کلیک → Create → Material:

| متریال | رنگ/تکسچر | کجا |
|---|---|---|
| `M_Wall` | کرمِ کثیف `#B8A88A` + Smoothness: 0 | دیوارها |
| `M_WallOld` | خاکستریِ کثیف `#6E6558` | سرداب |
| `M_Wood` | قهوه‌ای تیره `#4A3524` + Smoothness: 0.3 | در، پنجره، میز |
| `M_WoodLight` | قهوه‌ای روشن `#7A5C3D` | کابینت، قاب |
| `M_Carpet` | سرخِ فرش `#7B2D26` | فرش‌ها (Plane نازک) |
| `M_Mirror` | Albedo: خاکستری تیره، Metallic: 1، Smoothness: 0.9 | آینه‌ها |
| `M_Cloth` | خاکستری `#57534E` | پارچه‌ی آینه‌ها |
| `M_Ghost` | سیاهِ مطلق `#000000` | شبح |

### تکسچر رایگان (پیشنهاد — بازی را ۱۰۰٪ قشنگ‌تر می‌کند):
از `ambientcg.com` (رایگان): کلمه‌های `plaster` ، `old wood` ، `persian carpet`
را جست‌وجو کن → دانلود JPG → بکش داخل پروژه → در متریال، به **Albedo** بده.
+ **Normal Map** اگر بگذاری، دیوارها عمق پیدا می‌کنند (بعداً).

### لمس ایرانی‌تر: 🇮🇷
- **گچ‌بری ساده:** یک Plane با تکسچر نقش گچ‌بری بالای درها
- **فرش نقش‌دار:** روی M_Carpet تکسچر فرش بگذار — این همان «نقش سرو-ماه-خورشید» سرنخ معماست!
- **شومینه:** چند کوب قهوه‌ای + نور نارنجی ثابت (روشن، برای حس گرما-سرما)
- **تاقچه‌ها:** کوب‌های توکار دیوار با کوزه و کتاب (کوب‌های کوچک)

## بخش د: نورپردازی ترسناک (مهم‌ترین بخش!) 🕯️

### قانون موبایل: حداکثر ۱ چراغ Real-time فعال در یک لحظه!

| نور | نوع | تنظیم |
|---|---|---|
| نور ماه از پنجره | Directional | Intensity: 0.25 — رنگ آبیِ سرد `#8899BB` — ✅ Baked |
| چراغ‌های سقفی | Point | Range: 5 — Intensity: 0.8 — رنگ گرم `#FFB86B` — **Baked** |
| شمع‌های سرداب | Point | Range: 3 — Intensity: 1.2 — نارنجی `#FF7A2F` — **Real-time** (باید روشن/خاموش شوند) |
| نور سرداب | Spot | Range: 8 — Intensity: 0.6 — زردِ کم‌نور — Real-time |

### Bake کردن نور (کلییدی برای پرفورمنس!):

1. هر چراغ Bake‌شونده: Mode = **Baked**
2. همه‌ی دیوار/زمین/مبلمان: Inspector → بالای نام → تیک **Static** ✅
3. منوی **Window → Rendering → Lighting**:
   - ✅ Auto Generate را خاموش کن
   - دکمه‌ی **Generate Lighting** را بزن
4. صبر — یونیتی نورها را می‌پزد و کیفیت + سرعت روی گوشی عالی می‌شود.

چراغ‌هایی که با کد روشن/خاموش می‌شوند (شمع‌ها، فیوز): Mode = **Real-time** بمانند
و در их نواحی، اشیا را Static نکن.

### نکته‌های ترس:
- **تاریکی دوست توست:** بیشترِ خونه باید تاریک باشد؛ نور = اتمسفر، تاریکی = ترس.
- رنگ نورها را گرم کن (نارنجی کم‌نور) — سردی فقط نور ماه.
- **Light Cookies:** یک PNG دایره‌ایِ ناهموار به چراغ‌های سقفی بده — سایه‌های ناهموار = وحشت (جست‌وجو: «light cookie png»)

## بخش ه: انیمیشن‌های ساده (اختیاری اما جذاب)

پرده‌ی تکان‌خورنده، درِ لرزان و... با **Animator** ساده — فعلاً لازم نیست؛
فلیکر و شبح و صدا کافی است. بعداً اگر خواستی، سند تکمیلی می‌نویسیم.

## بخش و: بهینه‌سازی صحنه

1. هر اتاق: Static ✅ (بخش قبل)
2. کوب‌های تزئینی کوچک (کوزه و...) را **Static** کن و Mesh Collider به‌جای Box نگذار — Box بگذار.
3. دوربین: **Clear Flags: Solid Color** — پس‌زمینه سیاهِ مطلق.
4. دوربین Player: تیک **Occlusion Culling** لازم نیست — صحنه کوچک است.
