# ۶️⃣ راه‌اندازی ۶ معمای اصلی 🧩

> همه‌ی معماها روی ۳ سیستم بنا شده‌اند: **SequencePuzzle** (ترتیب)،
> **KeypadPuzzle** (کد)، **ItemSocketPuzzle** (جاگذاری).
> اینجا برای هر معما، تنظیمات دقیق می‌دهیم.

**قبل از شروع:** PuzzleManager را بساز:
Hierarchy → **Create Empty** → اسم: `PuzzleManager` → **Add Component → PuzzleManager**
همین! پرچم‌ها خودکار ذخیره و مدیریت می‌شوند.

## معما ۱: وصل کردن فیوز ⚡ (`fuse_fixed`)

قبلاً در سند ۴ ساختیمش. فقط حلقه را کامل کن:

1. کشوی آشپزخانه → آیتم `fuse` داخلش (PickupItem + Hidden Item در DrawerController)
2. جعبه‌ی برق → ItemSocketPuzzle → Required Item Id: `fuse`
3. در **On Filled** (UnityEvent جعبه‌ی برق):
   - `+` → همه‌ی چراغ‌های راهرو و نشیمن → `Light → enabled = true` — نه! چراغ را مستقیم نمی‌شود
     این‌طوری کنترل کرد؛ از این روش استفاده کن: چراغ‌های خونه را داخل یک
     **LightSwitch** بگذار (کلید اصلی راهرو) و در On Filled بگو:
     `+` → شیء کلید → `LightSwitch → ForceOn`
4. در **onInteract** خود جعبه (بخش Interactable): صدای «تیز» برق.

> نتیجه: فیوز در جعبه جا می‌گیرد → پرچم `fuse_fixed` → چراغ‌ها روشن →
> StoryManager مرحله‌ی «برق آمد» را با گویندگی و ترس اجرا می‌کند!

نکته: ItemSocketPuzzle پرچم `groupCompleteFlag` دارد — برای فیوز، بنویس: `fuse_fixed` ✅

## معما ۲: قفل کد اتاق مادربزرگ 🔢 (`grandma_room_open`)

### پنل قفل کد (UI)

در Canvas:
1. **UI → Image** → اسم: `KeypadPanel` — تمام‌صفحه، پس‌زمینه‌ی تیره
   - ✅ غیرفعال در شروع
2. فرزند: **UI → Text** → اسم: `DisplayText` — بالای پنل، فونت بزرگ (فقط ستاره نشان می‌دهد)
3. فرزند: یک Panel به اسم `Buttons` — **Grid Layout Group** — ۴ ستون
4. داخل Buttons: **۹ دکمه (1 تا 9)** + **0** + دکمه‌ی **C** (پاک) + دکمه‌ی **✕** (بستن)
   - روی هر دکمه‌ی عددی → On Click → `+` → شیء KeypadPanel →
     `KeypadPuzzle → PressDigit` → و در فیلد متن دکمه را بنویس: `1` (دقت: متنِ دکمه، نه اسمش)
   - دکمه‌ی C → `KeypadPuzzle → Clear`
   - دکمه‌ی ✕ → `KeypadPuzzle → Close`
5. روی `KeypadPanel` → **Add Component → KeypadPuzzle**:
   - Correct Code: `1348` (سال نذر — سرنخ: قاب عروسی!)
   - Solved Flag: `grandma_room_open`
   - Error Scare Event: `scare_whisper` (اشتباه = ترس!)

### قفل روی در

1. روی در اتاق مادربزرگ (DoorController با Start Locked ✅ و Unlock Flag: `grandma_room_open`) —
   یعنی در «با پرچم» باز می‌شود، نه با کلید.
2. یک شیء کوچک روی در (Cube کوچک) → اسم: `KeypadLock`
   - **Add Component → KeypadTrigger**:
     - Keypad Panel: `KeypadPanel`
     - Solve Flag: `grandma_room_open` (باید دقیقاً مثل پنل باشد!)

## معما ۳: فال حافظ — بیت‌های پاره 📜 (`poem_done`)

توی اتاق مادربزرگ: ۴ بیت حافظ پاره روی دیوار باید به ترتیب مرتب شوند.

1. چهار Plane کوچک روی دیوار (کاغذهای پاره) — هرکدام: `Verse_1` تا `Verse_4`
2. روی هرکدام → **Add Component → SequenceButton**:
   - Puzzle: بعداً (قدم بعد)
   - Answer Index: ترتیب صحیح — مثلاً Verse_3 = 0 ، Verse_1 = 1 ، Verse_4 = 2 ، Verse_2 = 3
   - Prompt: «چیدن بیت»
   - Select Sfx: صدای کاغذ
3. شیء خالی: `Puzzle_Hafez` → **Add Component → SequencePuzzle**:
   - Step Count: `4`
   - Solved Flag: `poem_done`
   - Mistake Scare Event: (خالی یا ترس ملایم)
   - Solved Voice Id: (اختیاری)
4. در هر SequenceButton، Puzzle را به `Puzzle_Hafez` وصل کن.
5. در SequencePuzzle → **On Step Correct** (IntEvent): `+` → بکش
   جعبه‌ی حافظ (کوب روی میز) → مثلاً فعال شدن نور آن قاب — برای سادگی:
   در On Solved فقط کافی است:
   - `+` → شیء `HiddenKey` (کلید داخل جعبه) → `GameObject → SetActive(true)`

کلید سرداب = یک PickupItem به اسم `HiddenKey` با آیتم `key_basement` که غیرفعال است
و بعد از حل شعر ظاهر می‌شود.

## معما ۴: آینه‌های پوشیده 🪞 (`mirrors_done`)

سه آینه در راهرو، پارچه رویشان. ترتیب = نقش فرش: **سرو ← ماه ← خورشید**

1. سه Plane عمودی با متریال شیشه‌ای (سند ۹) — اسم‌ها: `Mirror_A`, `Mirror_B`, `Mirror_C`
2. روی هر آینه یک Cube نازک (پارچه) — یا در همان آینه متریال پارچه‌ای که عوض می‌شود —
   ساده‌ترین راه: پارچه = Plane دیگر جلوی آینه که با تعامل محو می‌شود.
3. روی هر آینه → **Add Component → SequenceButton**:
   - Mirror_A (سرو) → Answer Index: `0`
   - Mirror_B (ماه) → Answer Index: `1`
   - Mirror_C (خورشید) → Answer Index: `2`
   - Prompt: «برداشتن پارچه»
   - در **On Selected**: `+` → پارچه‌ی همان آینه → `GameObject → SetActive(false)`
4. شیء خالی: `Puzzle_Mirrors` → **SequencePuzzle**:
   - Step Count: `3` / Solved Flag: `mirrors_done` / Solved Voice: `v_mirrors_done`
5. هر ۳ دکمه → Puzzle را وصل کن.
6. در **On Mistake**: `+` → شیء ترس (مثلاً شبح آینه) → `PeripheralGhost → Appear`

نتیجه: ترتیب غلط = شبح در آینه ظاهر می‌شود! 👻

## معما ۵: شمع‌های سرداب 🕯️ (`candles_done`)

سه شمع باید به ترتیب روشن شوند: **سرو ← ماه ← خورشید** (همان نقش فرش)

1. سه استوانه (Cylinder) + یک Light کوچک نارنجی روی هرکدام (نقطه‌ای، Range: 3)
   - اسم‌ها: `Candle_1` (سرو)، `Candle_2` (ماه)، `Candle_3` (خورشید)
   - هر Light در شروع: خاموش (تیک enabled بردار)
2. روی هر شمع → **Add Component → SequenceButton**:
   - Answer Index: `0` / `1` / `2` به ترتیب
   - Prompt: «روشن کردن شمع»
   - در **On Selected**: `+` → Light خودش → `Light → enabled = true` ✅
     (در UnityEvent می‌شود bool گذاشت: تابع Light.enabled با تیک ✅)
3. شیء خالی: `Puzzle_Candles` → **SequencePuzzle**:
   - Step Count: `3` / Solved Flag: `candles_done` / Solved Voice: `v_candles_done`
   - Mistake Scare Event: `scare_wrong_candle`
4. در **On Mistake** هم: همه‌ی شمع‌ها → `Light → enabled = false` (خاموشی ناگهانی + ترس)
5. در **On Solved**: `+` → شیء `NazrBox` (جعبه‌ی نذر) → فعال شدن/باز شدن —
   ساده: یک ItemSocketPuzzle نیست اینجا؛ جعبه = یک Interactable ساده که
   گویندگی `v_candles_done` و پخش `story_book` را می‌دهد.

در پایان: **کتاب قصه** (شیء `StoryBook`) — یک Interactable ساده:
- On Interact → `+` → شیء Endings → `EndingManager → ChooseStayEnding`

## معما ۶ (اختیاری): عکس‌های خانوادگی 🖼️ (`photos_done`)

سه قاب خالی در اتاق مادربزرگ + سه عکس در بازی (پنهان در کشوها و کابینت‌ها):

1. سه قاب = سه شیء با **ItemSocketPuzzle**:
   - قاب ۱: Required Item Id: `photo_1` — Filled Visual: مدل عکس داخل قاب (غیرفعال)
   - قاب ۲ و ۳ هم به همان ترتیب با `photo_2` و `photo_3`
2. در هر سه، فیلد **Group Sockets** را با هر سه قاب پر کن (سوکت‌های گروهی همدیگر را ببینند)
3. Group Complete Flag: `photos_done`

نتیجه: اگر هر ۳ عکس جا بروند → پایان‌ها «کامل» می‌شوند (متن و گویندگی بهتر).
