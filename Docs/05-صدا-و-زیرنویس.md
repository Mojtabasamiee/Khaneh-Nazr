# ۵️⃣ صدا، گویندگی و زیرنویس فارسی 🎙️

> هدف: صدای گویندگی خودت + زیرنویس فارسی قابل خاموش/روشن + صدای محیط.
> جدول کامل متن‌ها در `STORY.md` است — اینجا فقط نحوه‌ی فنی کار را می‌گوییم.

---

## قدم ۱: آماده کردن صداها

### ضبط
- با هر ضبط‌کننده‌ای (حتی گوشی در اتاق بی‌سد!) ضبط کن.
- فرمت نهایی: **MP3 (مونو، ۱۲۸kbps)** یا **WAV مونو**.
- اسم فایل = شناسه‌ی جدول STORY.md: `v_intro_1.mp3` ، `v_fuse_found.mp3` ...

### ایمپورت به یونیتی
1. پوشه‌ی `Assets/Audio/Voice` بساز و همه را بکش داخلش.
2. روی هر فایل در Project کلیک کن → در Inspector تنظیمات ایمپورت:
   - ✅ Force To Mono (اگر استریو است)
   - Load Type: `Compressed In Memory` (برای خط‌های کوتاه)
   - Quality: `70` (کافی برای گفتار، حجم کمتر)

## قدم ۲: کتابخانه‌ی گویندگی (VoiceLibrary)

1. راست‌کلیک در Project → **Create → خانه نذر → کتابخانه‌ی گویندگی** → اسم: `VoiceLibrary`
2. Inspector: **Size لیست lines را برابر تعداد گویندگی‌هایت کن** (از جدول STORY.md شمارش کن).
3. برای هر ردیف:
   - **Id:** `v_intro_1` (دقیقاً مثل جدول!)
   - **Subtitle:** متن زیرنویس فارسی (همان چیزی که گوینده می‌گوید)
   - **Clip:** فایل صدای مربوطه را بکش داخل
   - **Delay After:** `0.5` (چند ثانیه سکوت بعد از این خط)

> 💡 نکته: می‌توانی اول «همه‌ی متن‌ها» را بدون صدا وارد کنی و بازی را با
> زیرنویسِ بی‌صدا تست کنی — صداها بعداً یکی‌یکی اضافه می‌شوند. عالی برای شروع!

## قدم ۳: راه‌اندازی NarrationManager

در صحنه‌ی **House**:

1. Hierarchy → **Create Empty** → اسم: `Narration`
2. **Add Component → NarrationManager**
3. Library: فایل `VoiceLibrary` را بده.

### پخش از هر جا
- از کد: `NarrationManager.Instance.PlayById("v_intro_1")`
- از UnityEvent (بدون کد): در هر دکمه/رویداد → `+` → شیء Narration → `NarrationManager → PlayById` → شناسه را تایپ کن.
- چند خط پشت‌سرهم: از StoryManager استفاده کن (قدم ۵).

## قدم ۴: زیرنویس — همان چیزی که در سند ۳ ساختیم

SubtitleUI از سند ۳ آماده است. فقط یادت باشد:
- زیرنویس فقط وقتی نمایش داده می‌شود که **GameSettings.SubtitlesEnabled = true** باشد.
- خاموش/روشن کردن از **تنظیمات** (سند ۸) با یک Toggle انجام می‌شود.
- «پیام‌های راهنما» (مثل «در قفل است») همیشه نشان داده می‌شوند — زیرنویس نیستند، راهنمای بازی‌اند.

## قدم ۵: پیشبرد داستان با StoryManager

1. Hierarchy → **Create Empty** → اسم: `Story`
2. **Add Component → StoryManager**
3. در Inspector، لیست **Steps** — برای هر مرحله از داستان (جدول STORY.md):

### مثال: مرحله‌ی اول (ورود) — بدون شرط

| فیلد | مقدار |
|---|---|
| Step Name | ورود به خونه |
| Required Flags | (خالی — همان اول اجرا می‌شود) |
| Narration Ids | Size: 2 → `v_intro_1` ، `v_intro_2` |
| Horror Event Ids | (خالی) |
| Ambient Change | `house_quiet` |
| Start Delay | `1.5` |

### مثال: مرحله‌ی بعد از وصل برق

| فیلد | مقدار |
|---|---|
| Step Name | برق آمد — صدای قصه |
| Required Flags | Size: 1 → `fuse_fixed` |
| Narration Ids | `v_power_on` ، `v_story_heard` |
| Horror Event Ids | `scare_whisper` |
| Ambient Change | (خالی) |

هر وقت پرچم `fuse_fixed` روشن شود (سند ۶)، این مرحله خودکار اجرا می‌شود! 🎬

## قدم ۶: صدای محیط (Ambient)

1. Hierarchy → **Create Empty** → اسم: `AudioManager`
2. **Add Component → AudioManager**
3. لیست **Ambient Library** — صداهای محیط را با نام وارد کن:

| Name | فایل صدا (از Freesound.org بگیر) | Volume |
|---|---|---|
| `house_quiet` | باد ملایم + چوب جیرجیر دور | 0.7 |
| `house_night` | ملایم‌تر + جیرجیر نزدیک‌تر | 0.6 |
| `basement` | تونل تاریک، چکه‌ی آب | 0.8 |
| `ending_calm` | موسیقی آرام پایانی | 0.9 |

4. `Default Ambient` = `house_quiet` ← با شروع صحنه‌ی House خودکار پخش می‌شود.

## قدم ۷: صداهای تصادفی ترسناک

برای هر اتاق یک شیء خالی بگذار + **RandomSoundPlayer**:
- لیست صداها: جیرجیر، تق‌تق، نفس، بازشدن در دور...
- Min/Max Interval: `12` تا `30` ثانیه
- Require Flag: مثلاً `fuse_fixed` (تا بعد از برق شروع شود)
- Stop Flag: مثلاً `story_done` (وقتی پایان آمد ساکت شود)

## قدم ۸: جای‌گذاری صدا در اشیاء

هر کلاس تعاملی فیلد صدا دارد — فقط بکش و رها کن:

| کد | فیلدهای صدا |
|---|---|
| DoorController | openSfx / closeSfx / lockedSfx2 / unlockSfx |
| DrawerController | openSfx / closeSfx / creakSfx |
| Interactable (هر شیء) | interactSfx / lockedSfx |
| KeypadPuzzle | buttonSfx / errorSfx / successSfx |

صداهای رایگان: `freesound.org` (رجیستر رایگان) — جست‌وجو: «old door creak», «wooden drawer»...
