# ۱️⃣ نصب یونیتی و ساخت پروژه

> این سند برای شروعِ صفر است. اگر یونیتی را نصب کرده‌ای و پروژه داری، برو سراغ سند ۰۲.

---

## قدم ۱: نصب Unity Hub

1. به سایت [unity.com/download](https://unity.com/download) برو و **Unity Hub** را نصب کن.
   (Unity Hub مثل «فروشگاه» یونیتی است — همه‌ی نسخه‌ها از اینجا نصب می‌شوند)
2. Unity Hub را باز کن. اولین بار ازت می‌خواهد **حساب یونیتی** بسازی — رایگان است، با جیمیل بساز.
3. لایسنس: از منوی تنظیمات (چرخ‌دنده) → Licenses → **Get a free personal license** را بزن.

## قدم ۲: نصب یونیتی 2022.3 LTS

1. در Unity Hub از منوی چپ: **Installs** → دکمه‌ی **Install Editor**.
2. تب **LTS (Official releases)** را انتخاب کن — نسخه‌ی **2022.3.xx LTS** را بگیر
   (هر عددی که آخرش .3 LTS باشد، مثلاً 2022.3.60f1).
3. موقع نصب، این ماژول‌ها را **حتماً تیک بزن**:
   - ✅ **Android Build Support**
     - ✅ Android SDK & NDK Tools
     - ✅ OpenJDK
   - ❌ Visual Studio — اگر Visual Studio یا VS Code داری نگیر؛ اگر نداری بگیر (برای باز کردن کدها)
4. صبر کن نصب تمام شود (چند گیگ می‌شود — چای بساز ☕)

## قدم ۳: ساخت پروژه

1. Unity Hub → تب **Projects** → **New project**.
2. تنظیمات:
   - **Editor version:** 2022.3 (همانی که نصب کردی)
   - **Template:** ⚠️ حتماً **3D (Built-in)** — **نه** URP، **نه** HDRP!
   - **Project name:** `KhanehNazr`
   - **Location:** جایی که یادت بمونه
3. **Create project** را بزن. چند دقیقه طول می‌کشد.

## قدم ۴: آشنایی با پنجره‌ها (۳۰ ثانیه‌ای)

| پنجره | چیست |
|---|---|
| **Scene** | دنیای بازی — اینجا خونه را می‌سازی |
| **Hierarchy** | لیست همه‌ی اشیای صحنه |
| **Project** | فایل‌های پروژه (اسکریپت‌ها، صداها، متریال‌ها) |
| **Inspector** | مشخصات شیء انتخاب‌شده |
| **Game** | خروجی واقعی بازی — دکمه‌ی ▶ تست می‌کند |

## قدم ۵: تنظیمات اندروید

1. منوی **File → Build Profiles** (یا Build Settings در نسخه‌های قدیمی‌تر).
2. پلتفرم **Android** را انتخاب کن → **Switch Platform**. (چند دقیقه طول می‌کشد)
3. بعداً تنظیمات دقیق بیلد را در سند ۱۰ انجام می‌دهیم.

## قدم ۶: فونت فارسی 🅰️

یونیتی به‌طور پیش‌فرض فونت فارسی ندارد. فونت **Vazirmatn** (رایگان و آسان) را بگیر:

1. برو به: `github.com/rastikerdar/vazirmatn/releases`
2. فایل `vazirmatn-v33.003.zip` را دانلود و باز کن.
3. فایل‌های **TTF** (مثل `Vazirmatn-Regular.ttf` و `Vazirmatn-Bold.ttf`) را بردار.
4. در یونیتی: پنجره‌ی Project → پوشه‌ی `Assets` → راست‌کلیک → **Show in Explorer** (یا Reveal in Finder) →
   یک پوشه به اسم `Fonts` بساز و فایل‌ها را داخلش کپی کن.
5. برگرد به یونیتی — فونت ایمپورت می‌شود.

> 💡 **نکته‌ی مهم:** در کل این آموزش، برای متن فارسی از **UI Text (قدیمی)** استفاده می‌کنیم،
> **نه TextMeshPro** — چون TMP حروف فارسی را جدا-جدا نشان می‌دهد! متن‌های UI خود یونیتی
> فارسی را درست وصل می‌کند.

## قدم ۷: تنظیم Input

1. منوی **Edit → Project Settings → Player**.
2. پایین صفحه **Active Input Handling** را روی **Input Manager (Old)** بگذار.
   (یا Both — فرقی نمی‌کند، ولی Old باید فعال باشد چون کنترل لمسی ما با آن است)
3. اگر یونیتی ری‌استارت شد، نگران نباش — طبیعی است.

خاموش کن و برو سند بعدی!
