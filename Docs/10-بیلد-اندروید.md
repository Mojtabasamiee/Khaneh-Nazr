# 🔟 بیلد نهایی اندروید 📱

> هدف: خروجی APK قابل نصب + تنظیمات بهینه‌ی موبایل + چک‌لیست انتشار.

---

## قدم ۱: تنظیمات Player

**Edit → Project Settings → Player**:

### تب Other Settings:

| تنظیم | مقدار |
|---|---|
| Graphics APIs | ✅ Auto (یا فقط OpenGLES3) |
| **Scripting Backend** | **IL2CPP** ⚠️ مهم! |
| Api Compatibility Level | .NET Standard 2.1 |
| **Active Input Handling** | **Input Manager (Old)** |
| Target Architectures | ✅ ARMv7 + ✅ ARM64 |
| Optimize Mesh Data | ✅ |
| Color Space | Gamma (سریع‌تر) — Linear فقط اگر کیفیت نور لازم شد |

### تب Identification:

| تنظیم | مقدار |
|---|---|
| Package Name | `com.نامتو.خانهنذر` — مثلاً `com.mojtaba.khanehnazr` |
| Version | `0.1` |
| Minimum API Level | Android 8.0 (API 24) |
| Target API Level | Automatic (بالاترین) |

## قدم ۲: کیفیت و گرافیک

**Edit → Project Settings → Quality**:
- برای اندروید، سطح **Medium** را انتخاب کن و تنظیماتش:
  - Shadows: ❌ Hard Only یا کلاً خاموش (بیک نور سایه می‌دهد!)
  - Anti Aliasing: `2x MSAA` (یا خاموش برای گوشی ضعیف)
  - V Sync Count: Don't Sync

**Camera (پلیر)**:
- MSAA را اینجا هم می‌شود گذاشت.

## قدم ۳: بهینه‌سازی صداها و تکسچر

### صداها (هر فایل Audio):
- ✅ Force To Mono
- Load Type: Compressed In Memory (گفتار) / Streaming (موسیقی بلند)
- Quality: 70

### تکسچرها (هر فایل Texture):
- Max Size: `1024` (دیوارها/زمین) — `512` (آیتم‌ها)
- Format: **ASTC 6x6** (بهترین برای موبایل)
- Generate Mip Maps: ✅

## قدم ۴: کلید امضا (Keystore)

برای نصب روی گوشی و انتشار، امضا لازم است:

1. **Edit → Project Settings → Player → Publishing Settings**
2. **Keystore Manager → Create New → Anywhere**:
   - مسیر: یک فایل `khaneh.keystore` در جایی امن ذخیره کن
   - Password: یک رمز قوی — ⚠️ **یادداشتش کن! بدونش هیچ‌وقت آپدیت نمی‌تونی بدهی**
   - Alias: `khaneh` + رمز
3. برگرد Publishing Settings:
   - ✅ Custom Keystore → فایل را انتخاب کن و رمزها را بزن

> ⚠️ فایل keystore را **هرگز** در گیت‌هاب نگذار (در .gitignore هست ✅) و
> نسخه‌ی پشتیبانش را در جایی امن نگه دار!

## قدم ۵: بیلد!

1. **File → Build Profiles** (یا Build Settings)
   - Scene List: MainMenu اول، House دوم ✅
2. **Build** → اسم: `KhanehNazr-0.1.apk` → صبر (اولین بیلد IL2CPP طولانی است، شاید ۱۰-۲۰ دقیقه)
3. فایل APK را به گوشی بفرست (تلگرام/کابل) → نصب (اجازه‌ی منابع ناشناس لازم است)

### تفاوت APK و AAB:
- **APK** = برای تست و نصب مستقیم ✅ (همین را بساز)
- **AAB** = فقط برای انتشار در Google Play

## قدم ۶: چک‌لیست تست روی گوشی 🧪

- [ ] جوی‌استیک حرکت می‌دهد؟ سوایپ نگاه روان است؟
- [ ] تپ روی اشیاء تعامل می‌کند؟
- [ ] گویندگی پخش می‌شود؟ زیرنویس با Toggle خاموش/روشن می‌شود؟
- [ ] معماها حل می‌شوند؟ پرچم‌ها کار می‌کنند؟
- [ ] جامپ‌اسکر لرزش دارد؟
- [ ] بازی را ببند و باز کن → «ادامه» کار می‌کند؟
- [ ] هر دو پایان (ماندن/فرار) قابل رسیدن است؟
- [ ] FPS روان است؟ (فعال‌سازی: Developer Options → Profile GPU rendering)
- [ ] داغ نمی‌شود؟ (۱۵ دقیقه بازی پیوسته تست کن)

## قدم ۷: اگر کند بود 🔧

به ترتیب امتحان کن:
1. چراغ‌های Real-time را کم کن (فقط ۱-۲ تا در هر ناحیه)
2. نورها همه Baked؟ Static ها همه تیک خورده‌اند؟
3. تکسچرها Max Size را 512 کن
4. Quality → Shadows را کلاً خاموش کن
5. افکت‌های UnityEvent سنگین (انیمیشن‌های اضافه) را ساده کن
6. Target Frame Rate: در GameManager متد Start این را اضافه کن:
   `Application.targetFrameRate = 60;`

   - کافه‌بازار: آپلود APK + توضیحات فارسی + اسکرین‌شات
3. آیکن بازی: 512×512 — یک شمع در تاریکی 🕯️
4. اسکرین‌شات: ۴-۶ عدد از لحظه‌های ترسناک
