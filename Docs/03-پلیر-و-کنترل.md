# ۳️⃣ ساخت پلیر و کنترل لمسی

> هدف این سند: یک دوربین اول‌شخص که روی گوشی با جوی‌استیک حرکت می‌کند،
> با سوایپ نگاه می‌کند و با تپ روی اشیاء تعامل می‌کند.

---

## قدم ۱: ساخت پلیر

در Hierarchy صحنه‌ی **House**:

1. **راست‌کلیک → Create Empty** → اسمش را بگذار `Player`.
2. Position آن را صفر کن (Inspector → چرخ‌دنده → Reset).
3. روی Player کلیک کن → Inspector → **Add Component → Character Controller**.
4. CharacterController را تنظیم کن:
   - Height: `1.7`
   - Radius: `0.3`
   - Center: `(0, 0.85, 0)` ← تا کپسول از زمین شروع شود
5. Player را کمی بالا ببر: Position Y = `0.1`

## قدم ۲: دوربین

1. روی `Player` راست‌کلیک → **Camera** → اسمش می‌ماند `Camera`.
   (این دوربین جدید MainCamera می‌شود — دوربین پیش‌فرض صحنه را حذف کن!)
2. تنظیمات دوربین:
   - Position: `(0, 1.55, 0)` ← ارتفاع چشم
   - Field of View: `65` (برای ترس، عدد کمتر = حستنگی بیشتر! خودت تنظیم کن)
3. اضافه کردن کدها به **Player**:
   - **Add Component → PlayerController**
   - **Add Component → TouchLook**
4. در PlayerController → فیلد **Camera Transform** ← دوربین `Camera` را از Hierarchy بکش داخلش.

## قدم ۳: سیستم تعامل

1. روی `Camera` کلیک کن → **Add Component → PlayerInteractor**.
2. تنظیمات:
   - Interact Range: `2.6`
   - Interactable Mask: `Everything` (پیش‌فرض)

## قدم ۴: Canvas و HUD

**راست‌کلیک در Hierarchy → UI → Canvas** — Canvas به وجود می‌آید.
در Inspector همان Canvas:
- **Canvas Scaler** → UI Scale Mode: `Scale With Screen Size`
- Reference Resolution: `1080 x 1920` (پرتره) یا `1920 x 1080` (لنداسکیپ — پیشنهاد ما)
- Match: `0.5`

داخل Canvas این‌ها را می‌سازیم (هر کدام را جدا بنویس — به ترتیب):

### ۴-۱: جوی‌استیک حرکت (پایین چپ)

1. راست‌کلیک روی Canvas → **UI → Image** → اسم: `JoystickBase`
   - Anchor: پایین-چپ (Alt+Shift روی پیش‌نمایش anchor کلیک کن)
   - Width/Height: `300`
   - Pos: `(220, 220, 0)`
   - Source Image: می‌توانی یک دایره‌ی ساده بگذاری یا خالی (رنگ بده: Color → نیمه‌شفاف)
   - ✅ Raycast Target روشن باشد!
2. روی `JoystickBase` راست‌کلیک → **UI → Image** → اسم: `JoystickHandle`
   - Width/Height: `130` — رنگ روشن‌تر
   - Pos: `(0, 0, 0)`
3. روی `JoystickBase` → **Add Component → VirtualJoystick**
   - Handle: `JoystickHandle` را بکش داخلش
4. روی `JoystickBase` → **Add Component → Canvas Group** (برای شفافیت — کد خودش استفاده می‌کند)

### ۴-۲: دکمه‌ی تعامل (پایین راست)

1. راست‌کلیک Canvas → **UI → Button** → اسم: `InteractButton`
   - Anchor: پایین-راست، Pos: `(−240, 260, 0)`، Width/Height: `180`
   - متن دکمه: «لَمـس» (در فرزند Text)
2. روی دکمه در Inspector → بخش **On Click()** → `+`
   - شیء `Camera` را بکش داخلش → انتخاب تابع: `PlayerInteractor → TryInteract()`

### ۴-۳: دکمه‌ی انبار و مکث (بالای صفحه)

- `InventoryButton`: بالای وسط-چپ، متن «انبار» → On Click → `InventoryUI → TogglePanel`
- `PauseButton`: بالا-راست، متن «| |» → On Click → `PauseMenuUI → PauseGame`

### ۴-۴: متن راهنمای تعامل

1. راست‌کلیک Canvas → **UI → Text** (از دسته‌ی Legacy! نه TextMeshPro) → اسم: `InteractPrompt`
   - Anchor: پایین-وسط، Pos: `(0, 380, 0)`، Width: `800`، Height: `60`
   - Font: **Vazirmatn** (که در سند ۱ نصب کردی)
   - Font Size: `34` — Alignment: وسط
   - Color: سفیدِ گرم
2. روی همین Text → **Add Component → InteractPromptUI**

### ۴-۵: زیرنویس و پیام

1. راست‌کلیک Canvas → **UI → Text** → اسم: `SubtitleText`
   - Anchor: پایین-وسط، Pos: `(0, 140, 0)`، Width: `1700`، Height: `180`
   - Font: Vazirmatn، Size: `40`، وسط‌چین
2. یکی دیگر → اسم: `HintText`
   - Pos: `(0, 420, 0)`، Size: `30`، رنگ خاکستری روشن
3. یک GameObject خالی در Canvas بساز: راست‌کلیک Canvas → Create Empty → اسم: `SubtitleUI`
   - **Add Component → SubtitleUI**
   - Subtitle Text: `SubtitleText` / Hint Text: `HintText` را بده

> ⚠️ **چرا Legacy Text؟** متن‌های یونیتی فارسی را «وصل» می‌کنند؛ TextMeshPro نمی‌کند
> (حروف جدا-جدا می‌شوند). پس در این پروژه همه‌جا Text (Legacy) داریم.

## قدم ۵: تست در ادیتور 🖱️

قبل از بیلد، در ادیتور تست کن:
- **WASD** = حرکت | **ماوس نگه‌داشته + کشیدن** = نگاه | **E** = تعامل
- دکمه‌ی ▶ را بزن و ببین جوی‌استیک هم با ماوس کار می‌کند.

## قدم ۶: تست روی گوشی 📱 (بیلد سریع)

1. گوشی را با USB وصل کن → **Developer Options** روشن → **USB Debugging** فعال.
   (آموزش فعال‌سازی: در تنظیمات گوشی، شماره‌ی ساخت Build Number را ۷ بار بزن)
2. یونیتی: **File → Build Profiles** → Android → **Build And Run**.
3. اولین بار: ازت مسیر SDK می‌خواهد یا کلید امضا — همه را پیش‌فرض بگذار.
4. بازی روی گوشی بالا می‌آید — جوی‌استیک، سوایپ و تپ را تست کن!

⚠️ اگر لمس کار نمی‌کرد: Edit → Project Settings → Player →
**Active Input Handling** = Input Manager (Old) یا Both باشد.
