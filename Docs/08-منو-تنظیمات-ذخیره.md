# ۸️⃣ منو، تنظیمات، مکث و ذخیره‌ی بازی ⚙️

> هدف: صحنه‌ی MainMenu کامل + منوی مکث + پنل تنظیمات (با زیرنویس!) + سیستم ذخیره.

---

## بخش الف: صحنه‌ی MainMenu

صحنه‌ی `MainMenu` را باز کن (سند ۲ ساختیش).

### ۱. منوی اصلی

1. Hierarchy → **Create Empty** → اسم: `GameManager` → **Add Component → GameManager**
   (در هر دو صحنه باید باشد — خودش بین صحنه‌ها حفظ می‌شود)
2. یک GameObject خالی دیگر: `MenuUI` → **Add Component → MainMenuUI**
3. در Canvas (Scale With Screen Size مثل سند ۳):
   - **UI → Text** → اسم: `TitleText` — متن: «خانه‌ی نذر» — فونت Vazirmatn Bold، سایز بزرگ (۹۰)
   - چهار **UI → Button**: `NewGameButton` (بازی جدید) / `ContinueButton` (ادامه) /
     `SettingsButton` (تنظیمات) / `QuitButton` (خروج)
   - یک Text کوچک: `VersionText`
4. همه را به `MenuUI` بده (بکش داخل فیلدهای MainMenuUI).
   - دکمه‌های NewGame/Continue/Quit خودکار وصل می‌شوند (کد این کار را می‌کند!)
   - `SettingsButton` → On Click → `SettingsPanel → GameObject → SetActive(true)` ✅

### ۲. صفحه‌ی بارگذاری

1. در Canvas: **UI → Image** → `LoadingPanel` — تمام‌صفحه، سیاه — ✅ غیرفعال
2. فرزند: `TipText` (UI Text وسط، فونت Vazirmatn) و `ProgressBar` (UI Image —
   Image Type: Filled، Fill Method: Horizontal)
3. روی `LoadingPanel` → **Add Component → LoadingScreen** — مراجع را بده.
   - لیست **Tips** را با نکته‌های خودت پر کن (چند تا پیش‌فرض دارد)

حالا دکمه‌ی «بازی جدید» خودکار از صفحه‌ی بارگذاری استفاده می‌کند — چون
GameManager چک می‌کند اگر LoadingScreen موجود باشد از آن رد شود. ✨

### ۳. پس‌زمینه‌ی منو
- یک Plane با متریال تاریک + یک Light ملایم — یا یک Image تمام‌صفحه با تصویر
  تارِ خونه (بعداً اسکرین‌شات خود بازی را می‌توانی بگذاری!)

## بخش ب: پنل تنظیمات (منو + مکث = یکی)

1. در Canvas: **UI → Image** → `SettingsPanel` — نیمه‌صفحه وسط — ✅ غیرفعال
2. فرزندها:

| شیء | نوع | متن/تنظیم |
|---|---|---|
| `TitleText` | UI Text | «تنظیمات» |
| `SubtitlesToggle` | **UI Toggle** | برچسب: «نمایش زیرنویس» |
| `SensitivitySlider` | **UI Slider** | Min: کد تنظیم می‌کند |
| `SensitivityValueText` | UI Text | عدد فعلی |
| `MasterSlider` | UI Slider | «صدای کل» |
| `MusicSlider` | UI Slider | «موسیقی» |
| `SfxSlider` | UI Slider | «افکت‌ها» |
| `VoiceSlider` | UI Slider | «گویندگی» |
| `ResetButton` | UI Button | «پیش‌فرض» |
| `CloseButton` | UI Button | «بستن» |

3. روی `SettingsPanel` → **Add Component → SettingsUI** — همه‌ی مراجع بالا را بکش داخل.
   کد خودش مقادیر اولیه را می‌گذارد و تغییرات را ذخیره می‌کند. **هیچ اتصالی لازم نیست!**
4. `CloseButton` → On Click → `SettingsPanel → GameObject → SetActive(false)`
5. اسلایدرها Max = 1 (ولوم‌ها) — حساسیت را کد از ۰.۳ تا ۳ می‌گذارد.

### ★ زیرنویس — همان Toggle!

وقتی `SubtitlesToggle` خاموش شود:
- گویندگی‌ها پخش می‌شوند ولی زیرنویس نمایش داده نمی‌شود.
- بین اجراها هم حفظ می‌شود (PlayerPrefs).

## بخش ج: منوی مکث (در صحنه‌ی House)

1. در Canvas صحنه‌ی House: **UI → Image** → `PausePanel` — تمام‌صفحه تیره — ✅ غیرفعال
2. فرزندان: `ResumeButton` (ادامه) / `MenuButton` (منوی اصلی) / `QuitButton` (خروج)
   + یک جای خالی — پنل تنظیمات را هم می‌توانی کپی همین‌جا بگذاری (`SettingsPanel`)
3. روی `PausePanel` → **Add Component → PauseMenuUI**:
   - Panel: خودش / Settings Panel: پنل تنظیماتِ داخل مکث
4. دکمه‌ی مکث HUD (سند ۳) → On Click → `PausePanel → PauseMenuUI → PauseGame`
5. بقیه دکمه‌ها در Inspector:
   - Resume → `PauseMenuUI → ResumeGame`
   - Menu → `PauseMenuUI → BackToMenu`
   - Quit → `PauseMenuUI → QuitGame`

نکته: موقع مکث، بازی **خودکار ذخیره** می‌شود (SaveOnPause ✅).

## بخش د: سیستم ذخیره — از قبل آماده است! 💾

1. در صحنه‌ی House: **Create Empty** → اسم: `SaveManager` → **Add Component → SaveSystem**
2. همین! چرخه‌ی کار:

| اتفاق | نتیجه |
|---|---|
| پرچمی روشن شود | ذخیره‌ی خودکار |
| آیتمی برداشته شود | ذخیره‌ی خودکار |
| منوی مکث باز شود | ذخیره |
| «بازی جدید» | ذخیره‌ی قبلی پاک می‌شود |
| «ادامه» | پرچم‌ها + انبار + مکان پلیر + مرحله‌ی داستان برمی‌گردند |

فایل ذخیره: `Android/data/<package>/files/khaneh_save.json` روی گوشی.

## بخش ه: پایان دوگانه 🌘

1. در صحنه‌ی House: **Create Empty** → اسم: `Endings` → **Add Component → EndingManager**
2. پنل پایان در Canvas: `EndingPanel` (تمام‌صفحه سیاه، ✅ غیرفعال) با:
   - `EndingTitleText` (متن بزرگ وسط)
   - `EndingBodyText` (متن زیرش، چند خطی)
   - `BackToMenuButton` («بازگشت به منو»)
3. همه را به `Endings` بده. متن‌های چهار پایان (کامل/ناقص × ماندن/فرار) را
   از STORY.md کپی کن داخل فیلدهای متنی.
4. اتصال انتخاب‌ها:
   - شیء **کتاب قصه** (Interactable) → onInteract → `Endings → EndingManager → ChooseStayEnding`
   - شیء **درِ اصلی** (Interactable) → onInteract → `Endings → EndingManager → ChooseEscapeEnding`
5. Ids گویندگی پایان‌ها (از STORY.md): `v_end_stay_full` و...

> نکته: درِ اصلی = یک DoorController است که در پایان باید تعاملش را از
> «باز کردن در» به پایان بازی تغییر دهی — ساده‌ترین راه: یک Interactable ساده‌ی
> نامرئی روی در بگذار (Prompt: «ترک کردن خانه») که فقط ChooseEscapeEnding را صدا بزند.
