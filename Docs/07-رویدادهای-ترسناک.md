# ۷️⃣ رویدادهای ترسناک 👻

> هدف: ۵ رویداد ترس داستان (جدول STORY.md) + ترس‌های پراکنده.
> اصل بازی: **ترسِ اتمسفری زیاد، جامپ‌اسکرِ کم و حساب‌شده.**

---

## قدم ۱: راه‌اندازی مرکز ترس

1. Hierarchy → **Create Empty** → اسم: `HorrorManager`
2. **Add Component → HorrorEventManager**
3. لیست **Events** — برای هر رویداد یک ردیف:

### رویدادهای اصلی بازی

| # | Id | Scare Sfx | Shake | Sfx Position | Flickering Lights |
|---|---|---|---|---|---|
| 1 | `scare_drawer` | صدای ضربه‌ی شدید + میو | 0.15 | خالی | خالی |
| 2 | `scare_whisper` | زمزمه‌ی «قصه رو تموم کن» | 0.05 | راهرو | چراغ راهرو |
| 3 | `scare_mirror` | صدای شیشه/نفس | 0.1 | آینه‌ی سوم | خالی |
| 4 | `scare_basement_door` | ضربه‌ی در سنگین | 0.25 | در سرداب | خالی |
| 5 | `scare_wrong_candle` | فریاد کوتاه | 0.3 | سرداب | خالی |

- **Scare Sfx:** فایل صدا (Freesound: «slam», «whisper female», «glass shatter»)
- **Shake:** شدت لرزش دوربین — بیشتر = وحشتناک‌تر (بیشتر از 0.3 نرو، حالتوع می‌شود!)
- **Sfx Position:** اگر بدهی، صدا از همان نقطه می‌آید (۳بعدی) — واقعی‌تر است.
- **On Triggered:** رویدادهای اضافی — مثلاً `+` → JumpScarePanel → `JumpScare → Play`

## قدم ۲: جامپ‌اسکر تمام‌صفحه 💀

فقط برای `scare_drawer` (گربه!) و شاید یک لحظه‌ی دیگر استفاده کن — کم اما مؤثر.

1. در Canvas: **UI → Image** → اسم: `JumpScarePanel`
   - تمام‌صفحه (Anchor: Stretch) — Color: سیاه
2. فرزندش: **UI → Image** → اسم: `ScareImage`
   - Source Image: یک تصویر ترسناک (PNG شفافِ یک چشم/صورت از حالت‌های رایگان —
     یا موقتاً یک مکعب قرمز بگذار برای تست!)
   - Raycast Target: ❌ خاموش (نباید لمس را بگیرد)
3. روی `JumpScarePanel` → **Add Component → JumpScare**:
   - Scare Image: `ScareImage`
   - Scare Sfx: صدای شوک (Freesound: «jumpscare sting»)
   - Hold Duration: `0.7`
   - Shake Intensity: `0.35`
4. وصل کردن: در HorrorEventManager، رویداد `scare_drawer` → On Triggered →
   `+` → `JumpScarePanel` → `JumpScare → Play`

## قدم ۳: چراغ سوسوزن 💡

1. روی هر چراغی که می‌خواهی سوسو بزند (شیء دارای Light) → **Add Component → FlickerLight**
2. تنظیمات:
   - Flicker From Start: ❌ (فقط وقت رویداد)
   - Long Dark Chance: `0.12` (گاهی کاملاً خاموش می‌شود!)
3. در HorrorEventManager، رویداد `scare_whisper` → Flickering Lights → چراغ راهرو را بکش داخل.

## قدم ۴: شبحِ گوشه‌ی چشم 👁️ (ترسِ امضای بازی!)

یک سایه/سیلیوئت که فقط وقتی «نگاهش نمی‌کنی» هست:

1. یک مدل ساده بساز: **Cylinder** کشیده و تیره (Scale: `(0.4, 1.6, 0.4)` — متریال کاملاً سیاه)
   یا یک Plane با تصویر سایه‌ی دختر (PNG شفاف، Billboard)
2. اسم: `GhostHallway` — در انتهای راهرو بگذارش.
3. **Add Component → PeripheralGhost**:
   - Mode: `CornerOfEye`
   - Vanish Angle: `35`
   - Appear Sfx: زمزمه‌ی بسیار آرام
4. در شروع غیرفعال نیست — خودش نامرئی است. فعال‌سازی:
   - از UnityEvent هر شیء: `+` → `GhostHallway` → `PeripheralGhost → Appear`
   - مثلاً در On Triggered رویداد `scare_mirror`

خود شبح: اگر بازیکن مستقیم نگاهش کند یا نزدیک شود، محو می‌شود. بدون هیچ جامپ‌اسکری —
فقط «دیدم؟... نه، چیزی نبود» 😱

## قدم ۵: Trigger های ترس — کی چه چیزی؟

### روش ۱: از StoryManager (سند ۵)
مراحل داستان فیلد **Horror Event Ids** دارند — مثلاً مرحله‌ی «برق آمد» → `scare_whisper`.

### روش ۲: از UnityEvent اشیاء
- کشو (اولین بار): DrawerController → onInteract → `HorrorManager → HorrorEventManager → Trigger` → بنویس `scare_drawer`
- قفل کد اشتباه: KeypadPuzzle → Error Scare Event: `scare_whisper`
- آینه‌ی اشتباه: SequencePuzzle → On Mistake → Trigger `scare_mirror`

### روش ۳: تریگرهای مکانی (وارد شدن به ناحیه)
یک شیء خالی + **Box Collider** (✅ Is Trigger) + اسکریپت کوچک:

```csharp
using UnityEngine;

public class HorrorTrigger : MonoBehaviour
{
    [Tooltip("شناسه‌ی رویداد ترسناک")]
    [SerializeField] string eventId = "scare_whisper";
    [Tooltip("فقط یکبار اجرا شود؟")]
    [SerializeField] bool once = true;
    bool used = false;

    void OnTriggerEnter(Collider other)
    {
        if (once && used) return;
        if (!other.CompareTag("Player")) return;
        used = true;
        if (HorrorEventManager.Instance != null)
            HorrorEventManager.Instance.Trigger(eventId);
    }
}
```

این فایل را در `Assets/Scripts/Horror/HorrorTrigger.cs` ذخیره کن.
کاربرد: راهروی تاریک که در آن یکبار زمزمه می‌آید، پله‌ی سرداب و...

## قدم ۶: قانون طلایی ترس

1. **سکوت قبل از شوک.** چند ثانیه هیچ، بعد ترس.
2. **جامپ‌اسکر = حداکثر ۳-۴ بار در کل بازی.** بیشترش → تکراری و خسته‌کننده.
3. **ترس اصلی = صدا.** ۸۰٪ ترس از گوش است، نه چشم.
4. **شبح را کم ببین.** هرچه کمتر دیده شود، ترسناک‌تر.
5. **بعد از هر ترس، جایزه:** گویندگی، آیتم تازه، باز شدن مسیر.
