# خانه‌ی نذر — بازی ترسناک ایرانی برای موبایل 🕯️

> بازی اول‌شخص ترسناک برای **اندروید** با **یونیتی ۲۰۲۲.3 LTS** — بدون URP و بدون HDRP (رندر Built-in)
> یک خونه‌ی قدیمی ایرانی، نذری نیمه‌کاره، و صدایی که هر جمعه‌شب از سرداب می‌آید...

---

## 📖 داستان

آرش بعد از سال‌ها برای خواندن وصیت‌نامه‌ی مادربزرگش به خونه‌ی اجدادی برمی‌گردد.
مادربزرگ روزی نذر کرده بود که هیچ‌وقت کاملش نکرد — و همان نذر نیمه‌کاره است که هنوز
چیزی را در این خونه نگه داشته است. یا شاید... زندانی کرده است.

**داستان کامل + جدول متن‌های گویندگی:** [`Docs/STORY.md`](Docs/STORY.md)

---

## 🎮 امکانات

| سیستم | توضیح |
|---|---|
| کنترل لمسی موبایل | جوی‌استیک مجازی + سوایپ برای نگاه + لمس روی شیء برای تعامل |
| تعامل با محیط | درب‌ها، کشوها، کلیدها، فیوز، چراغ‌ها با سیستم Raycast |
| انبار (Inventory) | جمع‌آوری و بررسی آیتم‌ها با آیکون و توضیح فارسی |
| گویندگی + زیرنویس | سیستم صف پخش صدا + زیرنویس فارسی **قابل خاموش/روشن از تنظیمات** |
| ۶ معمای اصلی | فیوز برق، قفل کد (تاریخ شمسی)، فال حافظ، آینه‌های پوشیده، شمع‌ها، عکس‌های خانوادگی |
| رویدادهای ترسناک | جامپ‌اسکر، چراغ سوسوزن، شبح گوشه‌ی چشم، صداهای تصادفی خانه |
| پایان دوگانه | پایان «ماندن» یا «فرار» — بسته به خاطراتی که جمع کرده‌ای |
| ذخیره‌ی بازی | ذخیره/ادامه با JSON روی گوشی |
| منو و تنظیمات | منوی اصلی، مکث، تنظیم حساسیت و صداها، زیرنویس |

---

## 🚀 شروع سریع

1. **یونیتی 2022.3 LTS** را با ماژول **Android Build Support** نصب کن.
2. یک پروژه‌ی **3D (Built-in)** جدید بساز — نه URP، نه HDRP.
3. پوشه‌ی `Assets/Scripts` این ریپو را داخل پوشه‌ی `Assets` پروژه‌ات کپی کن.
4. پوشه‌ی `Docs` را هم کنار `Assets` بگذار (یا فقط بخوانش).
5. از **`Docs/01-نصب-و-پروژه.md`** شروع کن و مرحله‌به‌مرحله جلو برو.

> 💡 همه‌ی اسکریپت‌ها با **کامنت فارسی** نوشته شده‌اند و هر کدام بالای فایل توضیح
> «این کد چه می‌کند و کجا وصل می‌شود» دارد.

## 🗂️ ساختار کد

```
Assets/Scripts/
├── Core/        → GameManager ، تنظیمات ، ذخیره‌ی بازی
├── Player/      → کنترل پلیر ، جوی‌استیک ، سوایپ ، تعامل
├── Interaction/ → اشیای تعاملی (در ، کشو ، کلید ، چراغ)
├── Inventory/   → آیتم‌ها و انبار
├── Narration/   → گویندگی و زیرنویس
├── Audio/       → موسیقی و صدای محیط
├── Horror/      → رویدادهای ترسناک
├── Puzzles/     → سیستم معماها
├── Story/       → پیشبرد داستان و پایان‌ها
└── UI/          → منوها و تنظیمات
```
